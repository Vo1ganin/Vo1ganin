# Data tools & AI workflows

Open-source tools for market data, blockchain APIs and research automation. Python and SQL, with an emphasis on reproducible collection, data quality and clear documentation.

## Provider skills

The [collection](https://github.com/Vo1ganin/crypto-claude-skills#skills) is the canonical source. Individual provider repositories are generated distributions for installing a single skill.

[Dune](https://github.com/Vo1ganin/dune-skill) · [Solscan](https://github.com/Vo1ganin/solscan-skill) · [Nansen](https://github.com/Vo1ganin/nansen-skill) · [Solana RPC](https://github.com/Vo1ganin/solana-rpc-skill) · [DexScreener](https://github.com/Vo1ganin/dexscreener-skill) · [CoinMarketCap](https://github.com/Vo1ganin/coinmarketcap-skill)

## Focus

- Reliable data collection: batching, pagination, retries and resumable outputs.
- Research workflows: consistent identifiers, source timestamps and coverage checks.
- Practical documentation: setup, API requirements, examples and limitations.
